esmUi5 demos

The same Todo app (Component, manifest.json, i18n, XML view, controller), twice. Both use browser ES modules without a UI5 CDN loader or app bundler; esm/ imports UI5 modules by path, while bundles/ loads them by name through the esmUi5 runtime.

  • esm/: one ES module per UI5 module, import Controller from "../../../esm/sap/ui/core/mvc/Controller.js"
  • bundles/: shared lazy package chunks, no per-module facade files; load UI5 modules by name with require(["sap/ui/core/mvc/Controller"])
