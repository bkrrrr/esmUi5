esmUi5 demos

The same Todo app (Component, manifest.json, i18n, XML view, controller), twice. Both import UI5 with plain import statements, no loader, no import map, no bundler at runtime.

  • esm/: one ES module per UI5 module, import Controller from "../../../esm/sap/ui/core/mvc/Controller.js"
  • bundles/: one file per npm package, import { "sap/ui/core/mvc/Controller" as Controller } from "../../../bundles/sap.ui.core.registry.js"
